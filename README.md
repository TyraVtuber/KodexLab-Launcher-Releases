## Acerca del proyecto

**KodexLab Launcher** es una aplicación de escritorio desarrollada para
centralizar la administración y el acceso a distintas experiencias de
**Minecraft Java Edition**, con especial atención a su uso en eventos de
la comunidad.

Este repositorio está dedicado a publicar las versiones compiladas del
launcher y los archivos necesarios para distribuir sus actualizaciones.

> El código fuente del proyecto se mantiene en un repositorio privado.
> Este espacio contiene únicamente los archivos destinados a
> distribución.

## Descargar

Consulta las versiones disponibles en la página oficial:

**[→ Descargar KodexLab
Launcher](https://github.com/TyraVtuber/KodexLab-Launcher-Releases/releases)**

En cada publicación encontrarás el instalador correspondiente y, cuando
aplique, los archivos de metadatos utilizados por el sistema de
actualización.

### Instalación en Windows

1.  Abre la página de
    [Releases](https://github.com/TyraVtuber/KodexLab-Launcher-Releases/releases).
2.  Selecciona la versión que quieras instalar.
3.  Descarga el archivo `KodexLab-Launcher-Setup-<versión>.exe`.
4.  Ejecuta el instalador y sigue las indicaciones en pantalla.
5.  Cuando termine la instalación, abre KodexLab Launcher.

Descarga los instaladores únicamente desde este repositorio oficial.

## Funcionalidades

-   **Administración de cuentas:** gestión de perfiles y cuentas de
    Minecraft.
-   **Gestión de instancias:** organización de diferentes instalaciones
    del juego.
-   **Configuración centralizada:** acceso a los ajustes del launcher
    desde una sola aplicación.
-   **Actualizaciones automáticas:** soporte integrado para distribuir
    nuevas versiones.
-   **Conservación de datos:** configuración del instalador orientada a
    preservar los datos de la aplicación al desinstalar.

La disponibilidad de cada función puede variar según la versión
publicada.

## Soporte

Si encuentras un problema con el instalador o con una versión publicada,
utiliza los canales de soporte habilitados por el equipo de KodexLab.

Al reportar un inconveniente, incluye, cuando sea posible:

-   La versión del launcher.
-   Tu versión de Windows.
-   Una descripción clara del problema.
-   Los pasos necesarios para reproducirlo.
