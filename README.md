# KodexLab Launcher

KodexLab Launcher es una aplicación de escritorio para acceder y
gestionar experiencias de Minecraft Java Edition, especialmente aquellas
organizadas para eventos de la comunidad.

Este repositorio reúne las versiones oficiales del launcher para Windows
y los archivos necesarios para su distribución y actualización.

## Descargas

Consulta la página de
[Releases](https://github.com/TyraVtuber/KodexLab-Launcher-Releases/releases)
para descargar la versión disponible más reciente.

Para instalarlo, descarga el instalador `.exe` de la versión que quieras
utilizar y sigue las instrucciones que aparecen en pantalla.

## Compatibilidad

-   Windows 10 y Windows 11
-   Arquitectura de 64 bits (x64)
-   Minecraft Java Edition
